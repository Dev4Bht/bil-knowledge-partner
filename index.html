Every answer comes with the page it came from.

BIL Knowledge Partner reads only approved documents and answers staff questions with the exact page behind each claim. When the documents do not say, or disagree, it tells you instead of guessing.

§ 2

Six roles

One job each, and one rule each that holds.

This is a bounded workflow, not an autonomous system. The roles run in a fixed order with limits set in code, and they are the same names you saw in the log.

The six roles, what each does, the rule it cannot break, and what does the work
RoleWhat it doesThe rule it cannot breakDone by
1SupervisorReads the question and plans the search: business line, today's policy or its history, what to look for.A fixed, small number of searches per question. It asks you to clarify only when it cannot go on.Model, limits in code
2RetrievalFinds passages by keywords and by meaning together, each with its document, version, page and section.Your permissions are applied inside the search. A passage you may not read is never retrieved, so no model sees it.Database search
3Policy & VersionLeaves out drafts and superseded versions, says when it did, and looks for current documents that disagree.A conflict is reported only when code finds both quotes in the documents and their figures really differ.Model proposes, code decides
4SynthesisWrites short claims using only the passages found, each tied to its source.If the passages do not answer the question, it says so instead of filling the gap.Model
5VerificationChecks each citation exists, is readable by you, and matches the figures; then asks whether the source supports the claim.It may search once more. After that it declines. No citation, no answer.Mostly code, one model check
6Bilingual ResponseDrafts a reply in English for a staff member to review before anything is sent.Nothing is sent to a customer. Staff review and edit every draft.Model

§ 3

What it refuses

Four things it will not do.

No source, no answer.

Every claim carries the document, version and page it came from, and each source opens that page in the document viewer. A claim the sources do not support is rejected before you see it.

No quiet tie-breaks.

Only approved current versions answer by default. When two current documents give different figures, it quotes both and sends the question to their owners instead of picking one.

Test documents, recorded runMemo A says 10 working days. Memo B says 20 working days. No reply is drafted.

No access, no retrieval.

Permissions are checked in the search itself, before any text reaches a language model, and again when a file is opened. A document you may not read is answered as “not found”, the same as one that does not exist. Drafts are never searchable.

No sending.

Replies are drafts marked “Review before use”. Nothing goes to a customer automatically, and it never decides whether a claim or loan is approved. Staff have the final say.
